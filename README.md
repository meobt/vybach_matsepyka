## Куди приходять відповіді

Коли Анюточка тисне «так» і коли надсилає день/годину, сайт шле повідомлення двома шляхами (досить, щоб спрацював один):

1. **Пуш у телефон — ntfy** (без реєстрації).
   Встанови застосунок **ntfy** (Android / iOS), натисни «+» і підпишись на тему:
   `matsepyka-jtso8oqgm4trc0`
   Або відкрий https://ntfy.sh/matsepyka-jtso8oqgm4trc0 у браузері й дозволь сповіщення.

2. **Лист на пошту — FormSubmit.**
   Перший раз FormSubmit надсилає на `me.o.b.t2@gmail.com` лист «Activate Form» — натисни в ньому кнопку активації.
   Щоб отримати цей лист, один раз сам пройди сайт до кінця (так → день → година → «Надіслати цепі») на справжній адресі сайту.

Перевірити пуш без сайту:

```bash
curl -d "тест 💛" https://ntfy.sh/matsepyka-jtso8oqgm4trc0
```
